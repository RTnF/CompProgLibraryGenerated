# 性能測定

問題・テストケース・時間とメモリの制限が定義された場合に測定します。管理した環境で実行し、問題とケースの出典、生成方法、検証用の値、入力規模、実装とコンパイラ、測定条件、時間とメモリの結果を記録します。測定環境の情報と実測値は Git の追跡対象外である `benchmarks/local/` に保存します。候補実装の比較では規模ごとの結果を残します。

小さい固定ケースは保存できます。大きいケースは出典または再生成方法を記録し、サイトの利用条件を守ります。通常の GitHub Actions ランナーの値を性能比較の根拠にしません。
