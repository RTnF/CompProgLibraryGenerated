# C++ 検証基盤

`merge_sort_bridge.py` は固定した Clang 22.1.4 と GCC 13.3.0 のヘッダで `cp::merge_sort` の構文木を読み、レビュー済みの正規化 SHA-256 と一致する場合に限って Lean モデルとの対応を認めます。モデルはソース固有の信頼済み変換として生成されます。C++ の任意のコードを検証する汎用変換器ではありません。ソースを変更したら構文木と意味対応を再レビューする必要があります。

`associative_array_bridge.py` は公開型別名と二つの公開関数の構文木、およびヘッダ全体の SHA-256 を確認し、レビューした `associative_array_model.lean.in` から Lean モデルを生成・照合します。`std::map` の意味・計算量契約と C++ からモデルへの対応は信頼前提です。
