# スカラーの標準ライブラリ契約

共通変換器で扱う標準操作の初期契約である。現在は同じ組み込み整数型または bool の二つの直接の書き込み可能な束縛に対する、値を捨てる文としての `std::swap` に対応する。標準ライブラリの意味と C++ → IR 対応は信頼境界である。利用者が同名の関数を書いた場合に、この契約を適用してはならない。

`verifier/scalar_stl.py` は Clang が解決した二引数の関数呼び出しを調べ、次の確認を通した場合だけ `Stmt.swap` に落とす。

- 呼び出しと定義が直接の入力ファイルに存在し、ソースのバイト位置が得られる。マクロ経由と別の include 先の定義は拒否する。
- 呼び出しの位置に、選択された関数へのポインタと `std::swap<正規化した整数型>` へのポインタが一致する `static_assert` を挿入した一時ソースを、固定 Clang で確認する。名前を見ただけの選択にしない。namespace を付けた呼び出しや、グローバルな using を介した呼び出しにもこの照合を行う。
- 対象型の具体化が固定 GCC ヘッダの `bits/move.h` のテンプレート本体をパターンとすることを AST の宣言 ID の対応で確認する。利用者の明示的特殊化は拒否する。さらに、そのテンプレート本体の正規化 AST が、別途 `<utility>` だけを読み取った標準環境の本体と一致することを確認する。

この確認は部品名やソース全体のハッシュから手書きモデルを選ぶ処理ではない。STL の特定の操作に対する明示的な契約である。標準ライブラリとコンパイラの正しさそのものを Lean で証明したとはしない。任意の関数呼び出し、再帰、ユーザー定義型の move/swap、間接参照、ローカル using 宣言、for の更新式等の非独立文としての呼び出しは未対応である。

## 意味・安全性・費用

二つのセルの元の値を保持してから、左に右の値、右に左の値を格納する。同じアドレスなら値は変わらない。両方の束縛が書き込み可能で、アドレスが存在し、セルの型が一致し、値が各型の範囲に入ることをモデルで検査する。失敗時は成功結果を返さない。セルの数と束縛を保持し、return と break を発生させない。

固定幅の値の3回の移動を読み出し・格納の各1として、抽象仕事量は6を追加する。呼び出し先の二つの参照束縛と一つのスカラー一時値を追加領域として、`State.observe 3` で観測する。参照の引数束縛・呼び出し制御や Lean のメモリ操作そのものは仕事量に含めない。これらは固定幅スカラーの時間・追加領域が一定であることを扱う契約で、実測値ではない。

`Proofs/CppState.lean` の `swap_canonical` は任意の型内の2値と後続セルについて交換、後続セル保持、仕事量6、追加領域5を証明する。`swap_alias` は同じセルへの二つの参照について値の保持を証明する。`swap_preserves_storage_and_work` は任意の成功した実行についてセル数・束縛を保持し、仕事量を6追加し、return・break を発生させないことを証明する。ループの実行枠についての不変性・一意性の定理も、新しい文を含む全 `Stmt` を対象にする。

## 検査と持ち込みコード

`tests/test_scalar_swap_ir.py` は整数の最小・最大値、符号なし64 bit、bool、同じセル、型・書き込み・アドレスの条件を確認する。C++ は UBSan で実行する。同名の通常関数・関数テンプレートと、利用者が定義した `std::swap<int>` の特殊化を拒否することも確認する。

元の `experiments/library/cpp/number_theory/floor_sum.hpp` の `floor_sum_unsigned` 本体を、ソースを変更せずに共通 IR と Lean 定義へ生成できる。独立した Python の直接和の計算を期待値として、1,080小規模入力と符号なし64 bit の境界2入力を元の C++・生成 Lean と比較する。符号なしの累積結果は `2^64` の剰余として比較する。元の C++ はテンプレートを先に include し、UBSan で実行する。法0はモデルが検査失敗として拒否することを確認し、C++ では実行しない。

これらの有限ケースとは別に、2種類の floor_sum の生成モデルに対する全入力の結果・停止・安全性・時間と追加領域の証明を公開登録している。signed 版は対象コンパイラの変換契約を明示する。[仕様と証明](floor_sum_experiment.md)を参照する。

```sh
python3 tests/test_scalar_swap_ir.py
python3 tools/check_public.py
```

include 先の関数内の swap も検査対象とする。位置を定義元の実ファイルで解決し、Clang VFS overlay で検査式を挿入する。コンパイル対象は元の翻訳単位であり、include 前に定義された特殊化やマクロ、相対 include の文脈を保持する。`tests/test_scalar_swap_ir.py` は相対パスの依存ヘッダ、値引数の内部呼び出しと生成 Lean の結果、include 元の特殊化と依存ヘッダ内の同名関数の拒否を確認する。4検査が成功した。
