# TreeSet

`set/tree_set.hpp` の `cp::TreeSet<T>` は重複なしの集合。既定の要素型は `long long`。

- `add(key)` は要素を追加する。既にあるキーを追加すると集合は変わらない。
- `remove(key)` は要素を削除する。不在のキーを指定すると集合は変わらない。
- `find(key)` は存在判定、`size()` は要素数を返す。
- `min()` と `max()` は非空の集合の最小値と最大値を返す。

比較は一貫した厳密全順序とし、元の `==` は比較の同値関係に一致するものとする。比較とコピーはキーの値を保持する。比較やコピーが非 const の左辺値を取る型を使える。要素数は `int` に収まるものとする。

比較と値の取り扱いを1回の単位操作とすると、`add`、`remove`、`find` は高々 `O(1 + log(n + 1))`、構築・両端の取得・`size` は定数時間。キーの保持に `O(n)` 領域を使い、1回の挿入で要素は高々1個増える。順序と各操作の結果、停止、手数、格納要素数は `Proofs/Cpp/TreeSet.lean` で検査する。標準容器の演算契約を利用する。 [C++ 標準の順序付き連想コンテナ](https://eel.is/c++draft/associative.reqmts)

## 元のソースからの変更

固定シードの treap を標準の順序付き集合に置き換えた。原本の比較が非 const の左辺値にも適用されるよう、private なラッパーは値のコピーと比較に可変キーを渡す。重複で件数が増える現象、不在削除での null 参照、要素の解放漏れ、コピー間で木を共有する不具合を修正した。コピーでは独立した集合を作り、要素数に比例する。 [修正記録](agent/fixes.md)
