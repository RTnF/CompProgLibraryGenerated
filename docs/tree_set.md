# TreeSet

`set/tree_set.hpp` の `cp::TreeSet<T>` は重複なしの集合。既定の要素型は原本の `ll` と同じ `std::int64_t`。

- `add(key)` は要素を追加する。既にあるキーを追加すると集合は変わらない。
- `remove(key)` は要素を削除する。不在のキーを指定すると集合は変わらない。
- `find(key)` は存在判定、`size()` は要素数を返す。
- `rank(key)` は、存在するキーの0始まりの位置を `{i, i + 1}` で返す。不在なら `{-1, -1}` を返す。
- `get_kth(k)` は昇順で0始まりの `k` 番目を返す。前提は `0 <= k < size()`。
- `find_lower(key)` は `key` 以下の最大値、`find_upper(key)` は `key` 以上の最小値を返す。該当するキーがなければ `std::nullopt` を返す。
- `min()` と `max()` は非空の集合の最小値と最大値を返す。

比較は一貫した厳密全順序とし、比較とコピーはキーの値を保持する。比較やコピーが非 const の左辺値を取る型を使える。要素数は `int`、格納枠の添字と途中の値は対象の整数型の範囲に収まるものとする。

現在の要素数を `n` とする。比較と値の取り扱いを1回の単位操作とすると、`add`、`remove`、`find`、`rank`、`get_kth`、`find_lower`、`find_upper` は最悪時 `O(1 + log(n + 1))`。空の構築、`min`、`max`、`size` は定数時間。検索は1本の経路を反復でたどり、追加領域は定数。挿入・削除では木の高さに比例する再帰スタックを使う。

AVL 木の各節点は部分木サイズ、高さ、両端の位置を保持する。削除で空いた枠は次の挿入で再利用する。格納枠数を `m` とすると、保持領域とコピー構築の時間・追加領域は `O(m)`。格納枠数は挿入で高々1増え、削除後も保持する。コピーは独立した集合を作る。コピー代入では代入先の旧格納枠の破棄にも時間を使う。ムーブ構築後の移動元は空になり、ムーブ代入は両者の内容を交換する。どちらも定数時間。`Proofs/Cpp/TreeSet.lean` は生成モデルに対して更新後の順序・平衡条件、各操作の結果・停止・手数を確認する。 [翻訳対象となる標準操作](translation.md)

## 元のソースからの変更

現在の原本 `experiments/library/cpp/set/set.hpp` は `std::set` を使う。公開版は部分木サイズを保持する AVL 木で順位、k 番目、上下検索を提供する。旧 treap にあった重複登録時の件数増加、不在削除での null 参照、解放漏れ、コピー間で木を共有する不具合は移植時に修正した。 [修正記録](agent/fixes.md)
