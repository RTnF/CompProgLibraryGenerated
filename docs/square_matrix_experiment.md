# SquareMatrix の修正候補

元ファイル `experiments/library/cpp/number/square_matrix.hpp` は、単項マイナスに加え、2026-11-02に比較と不要な最終二乗も修正済み。原本ではpow(ll)、行配列参照、公開mat配列とaggregate/trivial/standard-layoutの性質を維持した。修正候補は `experiments/verification/number/square_matrix.hpp` の `cp::SquareMatrix<T, n>` とする。元の `mat`、行参照 `operator[]`、`O()`、`I()`、加減乗算と累乗の API を維持する。名前空間への移動と、次の変更を行った。

## 元のソースからの変更

- `==` と `!=` は存在しない `x` ではなく各要素を比較する。
- 単項マイナスは各要素の負値を返却先へ代入する。元コードの式文は何も代入せず、未初期化の結果を返していた。
- `pow` は最後の指数ビットを処理した後に不要な二乗を行わない。修正前の元コードは `SquareMatrix<long long, 1>{{{LLONG_MAX}}}.pow(1)` でも不要な乗算による符号付きオーバーフローを起こした。
- 標準C++での次元は正数、指数は非負であることを明示する。指数の引数型は元のllと同じlong longを保ち、負の値はassertで拒否する。追加の次元static_assertは置かず、配列型の制約も元に合わせる。
- 配列は元と同じくメンバー初期化子を付けず、aggregate・trivial・standard-layoutの性質を保つ。Matrix{}はC++の集成体初期化により値初期化されるが、Matrix m;の整数要素は書き込んでから使う。
- 行参照には行番号の assert を加える。返却される行配列の列番号は引き続き呼び出し側の前提条件とする。

## 用途、前提、境界

固定次元の正方行列の計算に使う。次元はコンパイル時定数で `n > 0`。要素のコピー・代入・既定構築、使用する演算と比較が定義され、処理を終了できることを仮定する。`O()` は整数0から、`I()` は bool から要素を構築・代入するため、代数的な零と単位元として使う場合はそれぞれが零と一を表す必要がある。Matrix{}の値初期化を零行列として使うにはT{}も零である必要がある。Matrix m;という宣言は整数要素を初期化しない。

累乗の仕様には要素の半環の条件（加法の結合性と可換性、乗法の結合性、分配法則、零と単位元）が必要である。減算・単項マイナスの仕様には加法逆元が必要である。比較を行列の等値として使うには要素比較が同値関係である必要がある。浮動小数点の演算はこれらの厳密な代数法則を満たさないため、この記録は浮動小数点の誤差解析を完了したことを意味しない。

符号付き整数を使う場合、**最終結果だけでなく、実際に実行する全乗算と加算・減算・符号反転の中間値**が型の範囲に収まることを前提とする。最小値の符号反転も前提外である。元の不要な二乗は除いたが、すべてのオーバーフローを実行時に検出する API にはしていない。行と列の番号はともに `[0, n)`。`mat` は公開配列なので、直接のアクセスにもこの条件が必要である。行列オブジェクトと一時行列を確保できることも仮定する。

指数0は単位行列を返し、指数1は入力行列を返す。`+=`、`-=`、`*=` の右辺が自分自身であってもよい。乗算は全成分を一時行列に計算してから代入する。空行列・負の指数は仕様に含めない。assert が無効なビルドでもこれらの前提条件は必要である。

## 計算量の目標

既定構築Matrix m;の費用はTによる。long longの要素は初期化せず、Matrix{}の値初期化はO(n²)となる。要素の構築・コピー・比較・各演算を定数時間とすると、構築、零・単位行列、加減算、単項符号、最悪時の比較は O(n²)、乗算は O(n³)、累乗は O(n² + n³ log(e + 1)) の時間を要する。指数0は O(n²) である。配列を持つ行列の領域は O(n²)、複合加減算と比較の一時領域は O(1)、返却行列を作る演算・乗算・累乗の追加領域は O(n²)。これは実装の解析と証明目標であり、Lean による費用・領域の証明はまだない。

## 再現とテスト

```sh
python3 tools/check_import_element_count.py
python3 tools/check_import_square_matrix.py
```

前者は元のelement_countの型の不具合を再現し、修正済みの行列比較が具体化できることを確認する。後者は原本の単項マイナスとpow(1)の正常結果、tests/imports/square_matrix_source.cppの全API回帰を通常実行・ASan/UBSanで確認する。専用の原本回帰は候補と同じ81行列/6561組に加え、pow(ll)・行参照・公開配列と型traitを検査する。独自の要素型を使って、指数0/1/2/3/4/8/31/LLONG_MAXの実乗算回数がpopcount(e)+floor(log2(e))（e=0は0）になることも確認する。

修正候補のテストは2×2行列の各要素を `{-1, 0, 1}` とした全81行列と全6,561組について、構築、行アクセス、比較、加減乗算、単項符号と複合代入を確認する。乗算の参照式は2×2の各成分を直接計算する。累乗は指数0〜8を繰り返し乗算の参照結果と比較する。自己代入と複合代入の参照返却も確認する。

さらに1×1の `LLONG_MAX`・`LLONG_MIN` で指数0・1、要素-1で `LLONG_MAX`・`LLONG_MAX - 1` の指数、3×3の冪零行列を確認する。ライブラリの small template を先に include し、`element_count` の修正候補と同時に使う。固定 Clang の C++17 構文確認、GCC 13.3.0 の通常実行と ASan/UBSan は成功した。LeakSanitizer は ptrace 制約により無効とする。
