# modint

`library/modint/modint.hpp` は `cp::ModInt<m>`、別名 `mint` / `mint17`、階乗表 `fac`、`MAX_FAC=20000003`、`init()`、`C(n,k)` を提供する。必要な標準ヘッダを自身で include し、共通テンプレートを先に include した場合も使える。原本は `experiments/library/cpp/modint/modint.hpp`。

## 用途と前提

法は `2 <= m < 2^32`。各値は `[0,m)` に正規化される。符号付き・符号なしのテンプレート構築と `set`、取得、四則演算と複合代入、比較、単項符号、前後置増減、符号付き64 bit指数の `pow`、`inv`、ストリーム入出力を持つ。元の SFINAE、参照・値の返却、`constexpr` 指定を保持する。

`inv`、除算、負指数の `pow` を逆元・商として使うには法が素数で、逆元を取る値が非零であることが必要。合成数法でも加減乗算と非負指数は使える。逆元演算の実装値は常に Fermat 形の `x^(m-2) mod m` であり、合成数法で逆元になるとは限らない。零の逆元と零の負指数は assert に失敗する。`0^0=1` とし、負指数は `INT64_MIN` まで扱う。

整数入力と中間値は元の C++ 型の範囲に収まることを前提にする。加減乗算の64 bit中間値は全UInt32法について扱い、法を `2^31` 以下へ狭めない。整数の昇格と `%` は [翻訳規則](translation.md) の型付き契約に従う。符号付き128 bitを含む具体的な構築・setも回帰する。一般の利用者定義型からの構築は、その型の演算・変換契約の下で生成関数の意味を述べる。

`init()` は `fac[i]=i! mod 998244353` を全 `0<=i<MAX_FAC` について構築する。`C(n,k)` は init 後、`0<=k<=n<MAX_FAC` を前提に `n choose k mod 998244353` を返す。表と法は固定で、添字の検査や未初期化表の自動構築は行わない。

## モデルと証明

共通変換器 `verifier/lean_translate.py` がヘッダ全体から `Proofs/Cpp/Gen/Modint.lean` を生成する。クラスは1個のUInt32を持つ構造体、可変globalは明示的な `GlobalState` になる。`Proofs/Cpp/Modint.lean` が次を証明する。

- 構築と set の正規化、既定値0、get/mod/単項plus、値の1 word上界。
- 全UInt32法での加減乗算、増減、比較、単項minus、自由演算子の値と更新後self。後置は更新前の値を返し、自己代入も排除しない。
- 二分累乗のモデルとの一致、停止、非負・負指数、逆元、複合・自由除算の値と範囲。素数法では Fermat の純粋補題から逆元と商の法則を導く。
- 元の型を識別する標準ストリーム契約の下で、入力値の正規化、更新streamと返却streamの一致、正常に返らない場合の伝播。書式・locale・例外・I/O自身の費用は外側の契約に残す。
- 起動時の全要素0、init後の階乗表、Cの二項係数、表の保持、起動→init→Cの接続。

`ModIntMath` と既存 `PowMod` が算術・二分累乗の純粋な補題を提供する。`PrimeCertificate` は平衡試行除算を通常の `decide` で検査し、998244353の素数性を示す。`ModIntFactorial` は階乗と分母の非零、階乗商と二項係数の関係を示す。巨大な表は証明中に実行せず、端点を変数にした配列更新モデルを証明して元の定数へ適用する。C++を文ごとにヒープ上で記号実行する旧ModInt証明は使わない。

## 計算量と境界条件

| 操作 | モデルの時間 | 追加データ |
| --- | --- | --- |
| 構築・set・取得・比較・加減乗算・増減・単項符号 | O(1)、通常1～2 tick | O(1) |
| 非負pow(n) | O(1+log(n+1))、4+bitWidth(n) tick | O(1) |
| inv / 除算 | O(1+log m) | O(1) |
| 負pow(n) | O(1+log(abs(n)+1)+log m) | O(1) |
| 起動時の表構築 | O(N)、1+2N tick | N個のUInt32 |
| init | O(N)、2+4(N-1) tick | 既存のN要素の表と固定局所値 |
| C | 固定法では40 tick、一般の法の尺度ではO(1+log m) | O(1) |

表のO(1)は固定幅の組込み整数の演算・変換を基本操作として数える。利用者定義型の構築・setでは、その型の剰余・加算・変換の費用を外側の契約として加える。N=MAX_FAC。表のモデルデータは32N bit。二分累乗の3個のUInt64は192 bit以下、公開pow/invの固定caller envelopeを含めた選んだ作業データは768 bit以下。C++ヒープ・寿命やLean評価器のstackはこの尺度の対象外。入出力の時間と領域は標準ストリーム契約に依存する。

## 検査

`tests/modint.cpp` は公開ヘッダを共通テンプレートの後に include する。独立した整数演算・128 bit積・二分累乗を基準にし、複数の素数法、負倍数、最大幅法、最小指数、自己代入、前後置、型別構築、入出力をASan/UBSan付きで確認する。元の全20,000,003要素の階乗表と、末尾を含むCの端・対称性・Pascal関係も検査する。

`tests/diff/modint.py` は登録した公開ヘッダのC++と生成Leanを比較する。固定mint返却のCを含む同一driverのobject型を一致させるため、この登録ではm=998244353を使う。一般mの証明はその値に特殊化しない。別法・整数型・stream境界は専用の原本/生成モデルの回帰も保持する。状態を使わない差分コマンドだけではLeanのglobal初期化を実行せず、起動自体は専用検査と上記の全入力証明で確認する。

## 元のソースからの変更

公開版では名前空間 `cp` と必要な標準include・std修飾を付ける。元の全クラスAPI、テンプレート条件、別名、fac/C/init、配列長を保持する。

原本で見つけた負倍数の正規化、大きい法の加減算、最小指数、符号付き128 bitの分類、入力失敗時の未初期化一時変数は原本と公開版の両方で修正した。GCC 13.3.0 の `-std=c++23` では `std::is_signed_v<__int128>` が `false` になるため、符号付き `__int128` を型の一致でも判定する。非負指数の非公開 constexpr helper で pow/inv の相互再帰を除いた。詳細と再発防止の検査は [修正記録](agent/fixes.md) を参照する。
