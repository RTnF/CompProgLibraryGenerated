# mod61

`cp::mod61` と `cp::mul61` は、ローリングハッシュが使う法 `2^61 - 1` の演算である。元の `experiments/library/cpp/string/rolling_hash.hpp` の `rh_in::mod` と `rh_in::mul` に対応し、名前空間 `rh_in` と 64 bit の補助定数は、共通変換器が扱える形（関数内の定数、複合代入を使わない）に書き換えた。

- `mod61(x)`: 前提なし（`uint64_t` の全値）。`x % (2^61 - 1)` を返す（結果は `[0, 2^61 - 1)`）。
- `mul61(a, b)`: 前提 `a < 2^61`、`b < 2^61`。`2^61 - 1` に関して `a * b` と合同な値を返す。結果は `2^64` 未満（途中で桁あふれしない）だが、完全には約されていない。`mod61` を通せば `a * b % (2^61 - 1)` になる。
- 時間と領域: どちらも分岐とループのない定数時間、定数個の局所変数。`mod61` の仕事量は 120 以下、`mul61` は 300 以下（呼び出し側の引数評価を除く）。

共通の入れ子 vector 生成器（`verifier/nested_ir.py`）が C++ の AST から Lean の本体を生成する。ビット演算子 `&`、`|`、`^`、`<<`、`>>` は符号なし 32 / 64 bit 型に限って扱い、シフト量は範囲内の整数リテラルでなければならない（未定義動作の不在を静的に保証するため）。`Proofs/Mod61Call.lean` の `mod61_correct` と `mul61_correct` が、前提を満たす全入力について結果、停止、未定義動作の不在、仕事量と追加領域の上界を証明する。数学的な核心は `Proofs/Mod61Math.lean`（`2^61 ≡ 1` を使った乗算の恒等式）、本体の逐次の証明は `Proofs/Mod61Body.lean` と `Proofs/Mul61Body.lean` にある。

定理に含めていないこと: 呼び出し側のオブジェクトの内容が変化しないこと（個数、使用領域、仕事量、スコープは保存を証明している）。C++ のテストは `tests/mod61.cpp` で、`__uint128_t` の剰余を独立した基準として、境界値と乱数を照合する。
