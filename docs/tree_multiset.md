# TreeMultiSet

`library/set/tree_multiset.hpp` の `cp::TreeMultiSet<T = std::int64_t>` は、同じキーを複数個持てる順序付き集合である。元の `experiments/library/cpp/set/multiset.hpp` と同じ固定シードの xorshift と treap を使う。各ノードにはキー、個数、両部分木を含む個数の合計、優先度がある。異なるキーを新規挿入するたびに同じ翻訳単位の全インスタンスで優先度生成器を共有する。

## API

| 呼び出し | 結果 | 時間 |
| --- | --- | --- |
| `TreeMultiSet()` | 空の集合を構築する。割り当てを行わず `noexcept` | `O(1)` |
| `TreeMultiSet(const TreeMultiSet&)` | 個数と木の形を保って独立にコピーする | `O(m+1)` |
| `TreeMultiSet(TreeMultiSet&&)` | 木を移し、移動元を空にする。割り当てを行わず `noexcept` | `O(1)` |
| `add(key, n = 1)` | `n` 個追加し、追加後の個数を返す。0個の追加では状態を保存する | `O(h+1)` |
| `remove(key, n = 1)` | キーが存在して `n` 個以上あれば `n` 個取り除き、`true` を返す。それ以外は `false` を返し、状態を保存する | `O(h+1)` |
| `remove_all(key)` | キーの全出現を取り除き、取り除いた個数を返す | `O(h+1)` |
| `count(key)`, `size()` | キーの個数と集合全体の個数 | `O(h+1)`, `O(1)` |
| `min()`, `max()` | 空でない集合の最小・最大キー | `O(h+1)` |
| `get_kth(i)` | 個数込みで昇順に並べたときの0始まりの `i` 番目 | `O(h+1)` |
| `rank(key)` | キーの開始順位と直後の順位の組。未登録なら `{-1, -1}` | `O(h+1)` |
| `find_lower(key)`, `find_upper(key)` | 指定キー以下の最大キーと、指定キー以上の最小キー。それぞれ存在しなければ `nullopt` | `O(h+1)` |
| `enumerate(lo, hi)`, `enumerate_all()` | 半開区間 `[lo, hi)` 内、または全キーの `(キー, 個数, 親キー)` を昇順に返す | `O(d+1)` |
| `aoj_dump(lo, hi)` | 閉区間 `[lo, hi]` のキーを昇順に、個数分だけ `std::cout` に1行ずつ出力する | `O(d+q+1)` に出力自体の費用を加える |
| `verify()` | 各ノードの部分木合計を再計算して確認する | `O(d+1)` |

`h` は木の高さ、`d` は異なるキーの数、`m` は確保済みスロット数、`q` は出力行数である。固定シードに対して時間の上界は `h ≤ d` を使う。探索ループの作業領域は定数、再帰する更新や走査の作業領域は `O(h+1)` で、列挙の返却値は最大 `d` 行である。削除したスロットは次の挿入で再利用する。各集合が保持するスロットの最大数は、その集合が空から操作で到達した最大の異なるキー数に等しい。コピーは元のスロット数を引き継ぎ、ムーブは移動元のスロットを空に戻す。破棄は格納されている要素を解放する。

キーの `<` と `==` は整合した全順序を定め、比較・コピー・型変換は値の契約を満たす。列挙は元の `parent ? parent_key : -1` が選んだ共通型を経由して親の値を `T` に構築する。各操作には、その操作で使うキーの比較、コピー、変換または入出力が使用できることが必要である。コピー元が `const` の集合でも、元のキーのコピー構築子が非 const 参照を取る型を使用できる。

`get_kth(i)` では `i < size()` とする。入力と途中の値は型の範囲に収まることを前提とする。特に `rank` の結果の順位をそのまま使う範囲では上端が `INT_MAX` 以下で、Lean の符号変換の定理もこの条件下で順位の値を保存する。固定幅の優先度生成には64ビットの演算を使う。公開 CI は64ビット `size_t` の構成を検査する。

## 検証

公開ヘッダから `Proofs/Cpp/Gen/TreeMultiset.lean` を再生成する。 `Proofs/Math/TreeMultiset/` の純粋 treap へ、生成された木の配置と空きスロットを対応させる。 `Proofs/Cpp/TreeMultiset.lean` から、構築・更新・照会・列挙が返す値、停止と手数の上界を検査する。 `aoj_dump` は各キーと改行の挿入を標準出力の契約に従って順に適用する。書式化と出力先に依存する費用は挿入操作の費用に含める。カーネルで検査する契約と、C++ のサニタイザおよび C++/Lean 差分テストを組み合わせる。

## 元のソースからの変更

RAII で解放するスロットに置き換え、破棄・削除でキーを解放し、コピーでキーを独立に複製するようにした。コピーの修正に伴い、コピー中にキーの構築やメモリの確保が失敗すると例外が伝播する。最初の挿入まで deque の確保を遅らせ、既定構築とムーブ構築の `noexcept` を保った。既定型、既定個数、全メソッド、代入不可、優先度の生成順と親キーの変換規則を維持した。元のソースでもコピー・解放、個数ちょうどの削除の戻り値、0個の追加、空集合での最小・最大の検査、半開区間列挙の呼び出しと枝刈りを修正した。
