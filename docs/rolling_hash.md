# rolling_hash

`cp::rolling_hash::RollingHash`（`cp::MultiRollingHash` の型別名）は、整数列または文字列の部分列について、法 `2^61 - 1` の多項式ハッシュを返す。基数は `cp::rh_in::base` の先頭から最大16個を使う。既定の基数数は1。 `cp::SimpleRollingHash` は基数131のスカラー版。従来公開していた `cp::RollingHash<T>` のベクトル構築、スカラーの `hash(l,r)` と `hash(a)` は引き続き利用できる。

- `hash(l,r)` は半開区間 `[l,r)`、`hash(a)` は接頭辞 `[0,a)` を返す。空区間の各ハッシュは0。
- `match(t)` は昇順に候補を調べ、全基数のハッシュが一致する最初の開始位置を返す。 `match_custom(t,idx)` は `idx` に現れる順に調べ、最初の一致で終了する。一致がない場合とパターンが長すぎる場合は `std::string::npos` を返す。
- `starts_with(t)` と `ends_with(t)` は接頭辞と接尾辞のハッシュをそれぞれ照合する。照合結果はハッシュ値の一致を表し、衝突は起こり得る。
- 連続する開始位置または `idx` の有効範囲は `0…n-m`。指定順で一致が見つかった後の添字は参照しない。空のパターンは任意の有効位置で一致する。
- `T` は元と同じ4バイト以下の整数型。文字列は実行環境の `char` 値の列として入力する。整数値、列長、添字と途中の値は対応する型の範囲内とする。区間は `0 ≤ l ≤ r ≤ n`。通常の複数基数の操作は `0 ≤ strength ≤ 16`。基数数0の照合は空のハッシュ列同士を照合する。原本どおり負の基数数で構築すると表を作らず、ハッシュ表の照会には非負の基数数が必要。

## 計算量

入力長を `n`、パターン長を `m`、基数数を `s`、候補数を `k` とする。複数基数の整数列構築は時間と保持領域ともに `O(1 + s(n+1))`。文字列も同じ上界で、各基数の構築時に `O(n)` の文字変換領域を一時使用する。区間・接頭辞ハッシュは時間と出力が `O(1+s)`、出力以外の作業領域は `O(1)`。

長さが入力以下なら、通常・指定順探索は時間 `O(1 + s + sm + (1+s)k)`、接頭辞・接尾辞照合は `O(1+s+sm)`。整数列での追加領域は `O(1+s)`、文字列の照合ではさらに変換の `O(m)` 時間と領域を使う。単一基数版と従来公開のクラスは基数数1に相当する。

## 検証

変換器は `Proofs/Cpp/Gen/RollingHash.lean` を公開ヘッダから生成する。 `Proofs/Cpp/RollingHash.lean` は多項式の連結と区間切り出し、構築する表の値と長さ、照合が候補順の最初のハッシュ一致で停止することと操作回数の上界を証明する。ハッシュの演算は `UInt64` で扱う。文字列変換と旧公開クラスは同じ構築・照会仕様に接続する。C++ 検査はテンプレート先行 include、ASan/UBSan、および生成モデルと C++ の差分実行を含む。

## 元のソースからの変更

- 元の複数基数クラスを `cp::rolling_hash::RollingHash` として提供する。単一基数版は `cp::SimpleRollingHash`、共通関数と基数表は `cp::rh_in` に置く。
- 複数基数の表を基数ごとの行が連続する2本のベクトルにまとめる。区間ハッシュは左端から引く積を先に剰余へ還元する。
- 負の要素をハッシュへ加える前に `2^61 - 1` を足して正規化する。原本では符号なし変換で加算が折り返し、同じ内容の区間が独立に計算したハッシュと一致しないことがあった。
