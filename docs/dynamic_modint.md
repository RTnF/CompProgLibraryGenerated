# dynamic_modint

`library/modint/dynamic_modint.hpp` は、実行時に法を選べる `cp::DynamicModInt` を提供する。法は共有の `DynamicModInt::m` で、初期値は 998244353。値は 1 個の `std::uint32_t` フィールド `x` に保持する。法を変更するときは使用する値を新しい法で構築し直すか、現在の法に対して正規化済みの剰余であることを確かめる。

## API と前提

- 既定構築は 0。符号付き・符号なしのテンプレート構築と `set` は `[0,m)` に正規化する。`get`、前置・後置の増減、単項符号、四則演算と複合代入、等値比較、標準ストリーム入出力を使える。演算に渡す値は `x < m` を満たすこと。
- 法は `2 ≤ m < 2^32`。逆元、除算、負指数の `pow` の数学的な仕様は素数法と非零の逆元対象を前提にする。非負指数と加減乗算は合成数法でも使える。`0^0` は 1、負指数は `INT64_MIN` まで扱う。
- `cp::factorial(n)` は非負の `int` 添字で `n! mod m` を返す。`cp::factorial_inv(n)` は素数法で `0 ≤ n < m` の逆階乗を返す。`cp::dynamic_modint::C(n,k)` は素数法で `0 ≤ k ≤ n`、`k < m`、`n-k < m` の二項係数を返す。
- 各階乗表は最初の呼出しと法変更後に 0 番目を 1 として初期化する。その法で前に計算した prefix は、表を伸ばしても再計算しない。API は共有の法とキャッシュを使うため、同時実行中の変更は呼出し側で同期する。
- 整数入力と中間値は元の C++ 型の範囲に収まることを前提にする。利用者定義型による構築と `set` には、その型の剰余・加算・変換の契約を適用する。ストリームの書式、失敗、例外は標準ストリーム契約に従う。

## 証明と計算量

共通変換器が公開ヘッダから `Proofs/Cpp/Gen/DynamicModint.lean` を生成する。クラスの静的な法と二つの局所静的キャッシュは明示的な状態として受け渡す。`Proofs/Cpp/DynamicModint.lean` が算術・入出力の各入口、配列の伸長と法変更、二項係数を証明する。逆元は Fermat の補題と二分累乗モデルを使い、逆階乗表は各添字の階乗との積が 1 になる不変条件を保つ。

| 操作 | モデル上の時間 | 追加データ |
| --- | --- | --- |
| 構築、取得、比較、加減乗算、増減、単項符号 | O(1) | O(1) |
| 非負指数の冪 | O(1 + log(n+1)) | O(1) |
| 逆元、除算 | O(1 + log m) | O(1) |
| 負指数の冪 | O(1 + log(abs(n)+1) + log m) | O(1) |
| 通常階乗表を長さ F へ伸長 | O(F) | 表に F 個の 32 bit 剰余 |
| 逆階乗表を長さ I へ伸長 | O(I (1 + log m)) | 表に I 個の 32 bit 剰余 |
| キャッシュ命中 | 階乗と逆階乗は各 1 tick、二項係数は 8 tick | O(1) |

通常階乗の拡張先 F は `max(100000,n+1)`、逆階乗の拡張先 I は `min(m,max(100000,n+1))`。二項係数の費用は階乗 1 回と逆階乗 2 回の費用に定数を加えたもの。表の長さと時計の上界は Lean で証明する。拡張用の STL 操作は [信頼方針](trust_policy.md) の契約に従う。C++ の vector が保持する容量には過去の伸長も影響する。表を除く算術は固定幅の局所値を使う。ストリームの費用と利用者定義型の演算費用は契約に加える。

クラスと逆階乗表で共用する `cp::dynamic_modint_pow_word(base, exponent, modulus)` は、非零の法を明示して符号なし指数の冪を計算する。二分累乗のステップ数は `2 + bitWidth(exponent)`。

## 検査

`tests/dynamic_modint.cpp` は共通テンプレートに続けて動的版と静的版を include し、両方の組合せ関数を呼ぶ。最大幅の素数法、符号付き 128 bit 入力、最小指数、更新参照、ストリーム、法変更後の階乗と逆階乗を ASan/UBSan 付きで検査する。`tests/diff/dynamic_modint.py` は公開 C++ と生成 Lean の値・更新を順に比較する。原本の回帰では小さい素数法を繰り返し切り替え、Pascal の関係で二項係数を比較する。

## 元のソースからの変更

原本は `experiments/library/cpp/modint/dynamic_modint.hpp`。配布用ヘッダには標準 include、`std` 修飾と `inline` を付ける。静的版と動的版の `C(int,int)` を同時に使えるよう、動的版の `C` を `cp::dynamic_modint` に置く。静的な法・値のフィールド・テンプレート構築と `set`・演算子・階乗関数の各機能を保持する。

負の倍数と符号付き 128 bit の正規化、最大幅の法での加減算、最小指数、ストリーム入力失敗、法変更時のキャッシュを原本でも修正した。経緯と回帰検査は [修正記録](agent/fixes.md) にある。
