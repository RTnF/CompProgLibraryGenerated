# DisjointSet

`library/union_find/disjoint_set.hpp` の `cp::DisjointSet` は、要素を連結成分に分けて管理する。原本は `experiments/library3/cpp/Graph/UnionFind.hpp`。成分は大きさで結合し、根を探すと経路を圧縮する。

| 呼び出し | 結果 | 時間 |
| --- | --- | --- |
| `DisjointSet(n)` | `0` から `n-1` の要素を、それぞれ1個の成分にする | `O(n+1)` |
| `unite(a, b)` | 成分を併合し、併合後の根を返す。大きさが等しい場合は `a` 側の根を残す | `O(1+log(n+1))` |
| `same(a, b)` | 同じ成分に属するかを返す | `O(1+log(n+1))` |
| `root(a)` | 成分の根を返し、経路上の各要素から根へ直接つなぐ | `O(1+log(n+1))` |
| `size(a)` | `a` が属する成分の要素数を返す | `O(1+log(n+1))` |
| `getNum()` | 成分の個数を返す | `O(1)` |

`0 ≤ n < 2^31`、頂点引数は `0 ≤ a,b < n` とする。入力と途中の値は型の範囲に収まる。空集合の `getNum()` は0を返す。親と成分の大きさを格納する配列は `n` 要素で、成分数は別の整数に保持する。根をたどる再帰は1フレームあたり定数領域を使い、深さは `1 + log2(n)` 以下なので、操作時の追加領域は `O(1+log(n+1))`。

## 検証

生成された純粋関数を既存の `UnionFind` モデルに対応させる。根の成分の重みは実際の要素数と一致する。根でなくなるときの成分の大きさを各頂点に対応づけ、親の重みが子の2倍以上であることを経路圧縮と併合が保つ。各検索の手数は、頂点数の2を底とする対数に定数を加えた値で抑えられる。コピー後の独立した更新、空集合、同一成分の再併合、成分の大きさが等しい場合の代表元をC++で検査する。

## 元のソースからの変更
