# FlowGraph

`graph/graph_flow.hpp` は逆辺付き隣接リストを使う。既定型は `cp::FlowGraph<long long, cp::FlowEdge<long long>>`。空グラフと頂点数を受け取る構築、`add_node`、最大流・最小費用流それぞれの辺追加、隣接行を可変参照で返す添字演算子、ストリーム出力を備える。互いに逆向きの辺は同じ行に入る自己ループの場合も別々の要素を持つ。

- `max_flow(s, t)` は Dinic 法で残余グラフから送れる最大の追加流量を返す。始点と終点は異なる。
- `min_cost_flow(s, t, f)` は追加流量 `f` の最小費用を返す。実現不能時の返り値は `-1`。有効な最適費用も `-1` になる場合がある。
- `min_cost_flow_slope(s, t, f)` は `(0, 0)` から始まる流量と費用の列を返す。隣接点を直線で補間すると、その間の整数流量の最小費用になる。`f` の既定値 `F_MAX` は `numeric_limits<Cost>::max() >> 2`。
- 流量を送る呼び出しは残余容量を書き換える。最小費用流の上限が正なら、最後の増加路を全部送った後で上限を検査する。指定流量の費用は補間で求めるため、残余グラフには指定より多く流れた状態が残ることがある。指定流量0ではグラフを保存する。

## 前提と計算量

頂点番号は範囲内、数と容量と流量指定は非負とする。添字、費用、容量を含め、入力と途中の値は C++ の各型に収まるものとする。証明では整数を数学的整数で表す。最小費用流は、正容量の初期残余弧 `u → v` に対して `cost(u, v) + p(u) - p(v) ≥ 0` を満たすポテンシャル `p` を前提とする。可変参照で辺を変更した場合も、逆辺添字、費用の符号、容量などの残余グラフ条件を満たす。利用者が供給する辺型には、使用する辺構築子とメンバーがあり、それらが既定辺と同じ格納・更新契約を満たすことを仮定する。

`n` を頂点数、`m` を逆辺も含む残余弧数、`F` を指定した正の流量とする。最大流は `O(n + n²m)` 時間、最小費用流は `O(1 + Fn(n + m))` 時間。最小費用流の Bellman–Ford は各巡回で頂点の行も走査する。

最大流の追加領域は `O(n)`。幅優先探索のキューは高々 `n` 頂点、深さ優先探索の再帰は層が1つずつ進むので高々 `n` フレーム。各時点でレベルと現在辺の配列もそれぞれ高々 `n` 要素。最小費用流の追加領域は傾き列を含めて `O(n+F)`。距離・親頂点・親辺の3配列はそれぞれ `n` 要素で、返却時のコピーが同時に存在しても線形。傾き列は `F + 1` 点以下。`min_cost_flow` も内部で傾き列を保持する。

構築の時間と領域は `O(1+n)`。空構築と添字は定数時間で、頂点と辺の追加は償却定数時間、各追加で増えるグラフの要素数も定数。Lean の公開仕様は `Proofs/Cpp/GraphFlow.lean` にある。ストリーム出力の書式はプロジェクトの入出力方針に従い、C++ テストで検査する。

## 元のソースからの変更

自己ループを追加するときに順辺の逆辺添字を補正した。流量0を早期に返し、最小費用流の到達判定を親配列で行う。DFS では失敗した弧の次に内部カーソルを進める。修正と再発防止の証拠は原本の回帰と修正記録を参照。 [修正記録](agent/fixes.md)
